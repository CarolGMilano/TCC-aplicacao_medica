# Frontend Web

Frontend web da aplicação de acompanhamento de pacientes do projeto de TCC.

A aplicação permite o acompanhamento do processo de investigação e tratamento, oferecendo funcionalidades como gerenciamento de pacientes, consultas, procedimentos, médicos e visualização de indicadores.

## Tecnologias

* Angular 21
* Angular Material
* ApexCharts
* SCSS
* TypeScript
* JWT

## Pré-requisitos

Antes de executar o projeto, certifique-se de ter instalado:

* Node.js
* npm
* Angular CLI

## Instalação

Na pasta `frontend-web`, instale as dependências:

```bash
npm install
```

## Servidor de desenvolvimento

Para iniciar o servidor local:

```bash
ng serve
```

Após iniciar, acesse:

```text
http://localhost:4200/
```

A aplicação será recarregada automaticamente sempre que houver alterações nos arquivos do projeto.

## Desenvolvimento

Para criar um novo componente:

```bash
ng generate component nome-do-componente
```

Para consultar outros comandos disponíveis no Angular CLI:

```bash
ng generate --help
```

## Projeto

Este frontend faz parte do sistema desenvolvido para o Trabalho de Conclusão de Curso (TCC) e integra-se ao backend da aplicação para gerenciamento e consulta dos dados do sistema.
